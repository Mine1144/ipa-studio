ไทยซับ กำลังเตรียมระบบ…
กด “จับหน้าจอ” หรือ “เล่นคลิปในแอป” เพื่อเริ่ม

PiP เป็นหน้าต่างเล็กลอยทับ — พื้นที่ที่มันไม่ครอบก็แตะเล่นเกมได้ปกติ ย้ายไปมุมที่ไม่มี HUD ไว้

จอที่สอง (ซับเต็มจอทับเกม App Store)

ส่งภาพเกม + ซับไทยไปจออื่น (iPad / Mac / PC) ผ่าน Wi-Fi เดียวกัน — เล่นเกมบน iPhone เต็มจอ (แตะเล่นได้จริง) แล้วดูภาพ+ซับไทยเต็มจอบนจอที่สอง

เกมเว็บในแอป (ฝังเกมที่ build เป็นเว็บ)

เกม Ren'Py / RPG Maker / Twine ที่ export เป็นเว็บ → วางโฟลเดอร์เกมไว้ใน Files > ไทยซับ > Documents → เปิดที่นี่ เกมจะเล่นเต็มจอในแอป พร้อมซับไทยทับทับ

เปิดแอปอื่น (PiP ยังลอยทับอยู่)

เปิดแอป/เว็บอื่นแล้วซับไทยของเราจะยังลอยทับอยู่บนหน้าจอ (ต้องเปิด Overlay ไว้ก่อน)

เปิดเว็บในแอป (เอาเนื้อหาอื่นมาแปล — เต็มจอ)

พิมพ์ URL เช่น เกมบนเว็บ / ไลฟ์ Twitch / YouTube / เว็บนิยาย แล้วแอปจะเปิดเต็มจอ พร้อมวางซับไทยทับทับ (ต้องเปิด "จับหน้าจอ" ไว้ด้วยเพื่ออ่านข้อความ)
